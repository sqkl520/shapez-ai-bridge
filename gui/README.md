# shapez GUI — 本地管理界面（shapez-ai-bridge GUI）

一句话：**双击一个文件，用图形界面把 mod 装好、把桥接跑起来** —— 不用记任何命令。

> 适用：Windows。前置：已安装 [Node.js](https://nodejs.org) ≥ 20（`node --version` 能显示版本即可）。
> GUI 需要 Chrome 或 Edge（Windows 10 基本都有）；没有也不影响使用，浏览器里打开打印的网址即可。

---

## 一、启动（三种方式，挑一种）

### 方式 A：双击 `start.cmd`（推荐给新用户）

资源管理器里进入本仓库的 `gui` 文件夹，双击 **`start.cmd`**。会弹出一个黑色小窗（那是服务本体，别关），随后自动打开一个无地址栏的"应用窗口"——这就是 GUI。

### 方式 B：命令行

```bash
node gui/server.mjs
```

仓库根目录（`shapez-ai-bridge` 文件夹）下运行。终端会打印一行 `[gui] shapez-ai-bridge GUI on http://127.0.0.1:7801/`，浏览器自动打开。

### 方式 C：只想让服务跑着，不自动开窗

```bash
node gui/server.mjs --no-open
```

然后自己打开打印的网址（默认 http://127.0.0.1:7801/）。适合远程/自动化场景。

> 端口默认 **7801**；被占用会自动试 7802…7810。想指定端口：`node gui/server.mjs --port 7805`。

## 二、首次使用：跟着向导点三下

1. **开始** —— 首页点【开始】。
2. **环境检查**（自动跑）：逐项显示 Node / 游戏目录 / mods 目录 / 端口 / 浏览器是否就绪。
   - 游戏没装/找不到？黄条提示 + 两个按钮：【用 Steam 安装】（打开商店页）、【手动指定路径】（选目录）。**不装游戏也能先装 mod**，但启动游戏后才能连上。
   - 端口 7777 被别的程序占用？这里会直接显示占用进程，向导会让你换个端口。
3. **安装 mod** —— 点【安装 mod】，看到绿勾即成功（显示目标路径、sha256 前 8 位、备份文件名）。
   - **注意**：安装任何 mod 都会禁用 Steam 成就与拼图 DLC（shapez 官方行为，先于安装已警示）。
4. **配置**（可一路用默认值）→ **启动桥接** → 【启动 shapez.io】→ **运行冒烟测试**。
   冒烟 5/5 全绿 = 全链路打通，点【进入控制台】。

> 安装完 mod 后如果游戏**之前**已经开着，需要**重启游戏**一次，mod 才会被加载。

## 三、日常使用（控制台）

- 顶栏信号链：游戏 → Mod → 桥接 → AI，四个呼吸点显示各环节状态。
- 桥接卡片：启动/停止桥接；显示运行时长、端口、是否连上游戏。
- 日志控制台：桥接/安装/冒烟的实时输出（级别过滤、跟随滚动、下载）。
- 底行快捷：【打开快照目录】【复制 MCP 配置】（给 Claude Desktop 等 MCP 客户端用）【打开 mods 目录】。
- 设置页：改配置（端口/token/只读模式/快照目录/日志级别）、卸载 mod、清理备份（危险区）。

## 四、配置说明（`bridge.config.json`，位于仓库根目录）

GUI 表单保存后写入此文件；手改文件后回 GUI 刷新即可看到：

| 键 | 默认 | 含义 |
|---|---|---|
| `port` | `7777` | 桥接监听端口（1024–65535 的整数） |
| `token` | `null` | 桥接鉴权 token（null=不启用；设了需 ≥8 位可打印字符，建议 ≥16） |
| `read_only` | `false` | true 时桥接拒绝一切写操作（只观察） |
| `snapshot_dir` | `"./snapshots"` | 存档快照目录（相对仓库根） |
| `log_level` | `"info"` | `debug` / `info` / `warn` |
| `rpc_timeout_ms` | `30000` | 普通 RPC 超时（1000–600000） |
| `long_timeout_ms` | `180000` | 长操作（如冒烟）超时（1000–600000） |

GUI 自身状态（向导是否完成、手动指定的游戏目录）存于 `gui/.gui-state.json`，与桥接配置互不干扰。

## 五、常见错误与排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 `start.cmd` 黑窗一闪而过 | Node 未装/不在 PATH | 装 Node ≥20 后重试；或在 cmd 里跑 `node gui\server.mjs` 看报错 |
| 黑窗显示 `node is not recognized` | 同上 | 同上 |
| 页面显示"后端已断开" | GUI 服务进程被关了/崩了 | 重新双击 `start.cmd`；页面会尝试自动重连 |
| 向导说"端口被占用" | 7777 上有别的程序（含**手动开的桥接**） | 向导里换端口，或关掉旧桥接。若 7777 是你自己开着的外部桥接，GUI 会显示"已运行（外部启动）"，停止需回到原终端 Ctrl-C |
| 游戏里连不上（状态一直"等待游戏连接…"） | mod 装了但游戏没重启；或端口不一致 | 重启游戏；确认 mod 设置里的 ws 端口 = 桥接端口（默认 7777） |
| 安装失败，提示 mods 目录写不进去 | 权限/杀软 | 允许写入 `%APPDATA%\shapez.io\mods`；临时关闭杀软重试 |
| 日志里中文乱码（锟斤拷） | 终端代码页问题 | `chcp 65001` 后重开；GUI 的日志视图一般不受影响 |
| 防火墙拦截 | 部分安全软件拦 localhost | 允许 `node` 监听 127.0.0.1；排除 127.0.0.1 的系统代理 |
| 浏览器没自动打开 | 未找到 Chrome/Edge 或检测失败 | 手动打开终端打印的网址（服务永远可用） |

更多底层排查见仓库根 `README.md` 的 Troubleshooting 节。

## 六、卸载 / 清理

- GUI 设置页 → 危险区：【卸载 mod】（可勾选同时清理备份/游戏内 mod 设置）。
- 或命令行：`powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall`。
- GUI 自身不装任何东西：退出窗口即可，仓库目录删掉不会残留系统垃圾。

## 七、开发者信息

- `gui/server.mjs` — 零依赖 HTTP 服务（静态文件 + `/api/*` + SSE），仅绑定 127.0.0.1。
- 所有 `/api/*`（除 `/api/healthz`）需要 `X-GUI-Token`；token 在启动时随机生成，注入页面 `<meta name="gui-token">`；带 `Origin` 的请求必须是 `http://127.0.0.1:<port>` 否则 403。
- 验证脚本：`node gui/verify/api_acceptance.mjs`（B/C/D 组）、`node gui/verify/red_team.mjs`（红队）、`node gui/verify/dom_gate.mjs`（设计闸门）。结果写入 `docs/gui/VERIFICATION.md`。
