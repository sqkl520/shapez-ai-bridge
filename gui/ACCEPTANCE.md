> 供执行 Agent 与验证 Agent 共用。每一项：**怎么测 / 期望结果 / 谁来测**。
> 原则：能自动化的必须自动化；不能自动化的必须留下截图证据。

| 因素 | 基线值 |

## 冲突仲裁原则

- Agent 之间对同一测试结果不一致 → 以**能自动化复现的那个结论**为准
- 设计闸门（A 组）判定不一致 → 以静帧截图为最终证据
- 任何"我觉得没问题"的口头结论无效——必须落到命令输出或截图
