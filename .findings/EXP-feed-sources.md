# 实验：`feed_sources` 与槽位格式，两轮 A/B

2026-11-21。真实 LLM（本机 gateway，`gpt-5.6-luna`），n=10/组。
判据跑到 `buildTxPlan` 为止 —— **这是本实验与之前所有 prompt 实验最大的区别**。

## 为什么要这样测

前面几轮实验的判据是「计划的 `to` 是不是诊断点名那个槽」。
`tools/replay-plan.mjs` 把那些计划喂回 `buildTxPlan` 才发现：
**「选中根因 9/10，真能落地 1/10」**。

被预演闸门拒的多数不是路径挑得差，是**源头选错** ——
挑了一台 66 格外、路线横穿 165 段主干道的矿机。
而同一份世界上 `M13/M15`（绿矿，27~28 格，不切断任何下游）能直接落地。

所以这一轮：**判据从「选中」改成「落地」**。

## 第一轮：只加 `feed_sources`

| 指标 | A（无推荐） | B（有推荐） | p |
|---|---|---|---|
| 选中根因 | 8/10 | 10/10 | 0.303 |
| 真能落地 | 1/10 | 4/10 | 0.152 |
| 选中且落地 | 0/10 | 4/10 | **0.043** |
| from 落在推荐列表 | 0/10 | **10/10** | **0.000** |

B 组 10/10 选了推荐的那台（M13），A 组 10/10 选 M7。

**B 组一次预演闸门都没撞**（A 组撞了 7 次）。换掉源头后路径问题彻底消失。

剩下的 6 次失败全是同一件事：

```
to.port = "right"   ← 方位
to.port = "color"   ← 角色（正确）
```

全 20 个样本里 **9 个**写成方位名，而且全是 `right` ——
它们都指向 painter 的 `color` 槽，那槽恰好长在右侧。

根因是 MACHINES 段的格式 `输入=top:shape(←B107)/right:color(←无)`：
方位在前、角色在后。模型取了冒号前那个词。
更隐蔽的是 `right` 对 cutter 恰好是合法角色，所以这不是一眼可见的错值，
是**格式歧义**。

## 第二轮：`dir:role` → `role@dir`

改成 `shape@top(←B107)/color@right(←无)`：角色放最前，`@` 明确标注方位。

| 指标 | A（无推荐） | B（有推荐） | p |
|---|---|---|---|
| 选中根因 | 5/10 | **10/10** | **0.018** |
| **真能落地** | **0/10** | **10/10** | **0.000** |
| 选中且落地 | 0/10 | **10/10** | **0.000** |
| from 落在推荐列表 | 2/10 | **10/10** | **0.000** |
| `to.port` 写成方位 | 1/10 | **0/10** | —— |

**B 组 10/10 全部落地。**

A 组的失败模式是最好的对照：

```
7 次选 M7（66 格外的蓝矿）→ 5 次撞预演闸门（-191，62%）
2 次选 M13              → ambiguous_port
1 次参数写错
```

A 组的 `say` 是「from an available **blue** miner」—— 它按颜色挑，
颜色对上了，但它看不到距离，也看不到「覆盖这条路径会切断多少下游」。

## 两处改动的分工

| | 只加 feed_sources | 再加 role@dir |
|---|---|---|
| B 组落地 | 4/10 | **10/10** |
| `to.port` 错误 | 6/10 | **0/10** |

`feed_sources` 解决「选哪台」，`role@dir` 解决「端口怎么填」。
两者缺一不可 —— 第一轮证明了前者单独不够。

## 边界（必须说清）

**模型是 `gpt-5.6-luna`，不是历史实验用的 `virtual/opus`。**
本机 gateway 只提供这一个。所以：

- **可信**：`feed_sources` 让 from 命中率 0→100%（机制上无歧义）
- **可信**：`role@dir` 把 `to.port` 错误从 9/20 降到 1/20
- **方向可信、绝对值待验**：落地率 0/10 → 10/10。
  n=10 上的 0 vs 10 是极端比例，统计上很强，但真实世界不会这么干净。

## 复现

```bash
PROXY=1 node tools/exp-feed-sources.mjs --n 10 --out research/ai-plan/experiments/feed-sources-v2
node tools/exp-feed-sources.mjs --dry      # 只渲染 + 等价性自检
```
