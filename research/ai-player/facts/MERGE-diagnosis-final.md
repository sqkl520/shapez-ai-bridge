# 双分支汇合：精确诊断（rv 陷阱的最终确认）

> 这是 M4 系列实验的结论页。**5 次尝试、每次世界都无损恢复**，最终精确定位到**唯一**的剩余障碍。

## 最终诊断（列剖视，最清楚）

建成后的实际布局（`--keep` 模式保留现场后逐列 dump）：

```
x=154: 104{min} 103[0/0] 102[0/0] 101[0/0] 100[0/0] 99[0/0] 98[0/2]   ← 分支A 通道 ✓
x=155..158: 98[90/0] ×4                                              ← A 水平段（朝右）✓
x=159: 98[90/1] 97[0/0] 96{sta} 95..93[0/0] 92{tra}                  ← A 拐角(左转)✓ + stacker ✓
x=160..164: 100[270/*] 99..97[0/0]                                   ← B 水平段（朝左）✓
x=165: 116{min} ... 101[0/0] 100[0/1]                                 ← ★ B 的拐角：rv=1（向上）✗
```

**链条已完全连通**（无空洞），**唯一的问题在 `(165,100)`**：

| | rotation | rotationVariant | 实际行为 |
|---|---|---|---|
| 分支 A 的拐角 `(154,98)` | 0 | **2** | 从下上来 → **向右**转 ✓ |
| 分支 B 的拐角 `(165,100)` | 0 | **1** | 从下上来 → **向左**转 ✓ |

**两者看起都对！** 但物品仍停在 `(165,100)` 没往西走。

**真正原因**：B 的**水平段**在 `(160..164, 100)` 是 `r=270`（朝左），
而 B 的拐角在 `(165,100)` —— 水平段在拐角的**西侧**，方向也对（朝左，流向 (164,100)）。
**但 `(165,100)` 的 rv=1 表示"拐向被它朝向的左侧"** —— 它朝向 rotation=0（北），
rv=1 = 左转（相对北 = **西**）✓。

所以几何全对。**问题在物品来源**：`(165,101)` 是 `r=0 rv=0`（朝北），
它把物品送到 `(165,100)`——但 `(165,100)` 是**拐角格**，它的"上游"是 `(165,101)`，
而它自己的 rotation 是 0（北）——**游戏判定这个拐角格的"入口方向"与"出口方向"冲突**：
从南边进来、却要从西边出去，而 `rotationVariant` 只在**"有上游从侧面注入"**时才改变曲线朝向。

**即：`belt.js:161` 的自动定向算法产生的曲线变体，在"竖直进、水平出"的转角上，
只有当拐角格的 rotation 明确表示"出口方向"时才正确。**

## 结论（对布局编译器的硬需求）

**不要手放拐角。** 三种可行做法（按推荐度）：

### ✅ 方案 1：**全部用直线，用隧道穿越**（最稳）
把"竖直进 → 水平出"改成"竖直进 → 隧道 → 水平出"，
即**避免任何拐角格**。隧道（`underground_belt`）是 T1=5 格跨度，有明确的入口/出口对，
不依赖邻居自动定向。

### ✅ 方案 2：**用蓝图**（已实测保真，H7）
蓝图的 `e:[code,dx,dy,rot,...]` 里 `code` **含 rotationVariant** —— 粘贴时**直接指定**，
不经过自动定向。所以**只要能在离线算出正确的 code，拐角就一定对**。
→ 需要 `building_codes.js` 的 `getCodeFromBuildingData` 算法（**尚未实现，是明确的下一步**）。

### ✅ 方案 3：**先放拐角，再放邻居，最后重放拐角**
因为 rv 由邻居派生，可以在所有邻居就位后，**把拐角格 delete 再 place 一次**，
让它重新计算。成本低（2 次 API 调用/拐角）。

## 本次实验的完整价值

| 尝试 | 方法 | 结果 | 学到什么 |
|---|---|---|---|
| 1 | 手写坐标 | 失败（对角缺口） | 不能手算坐标 |
| 2 | 手写坐标 + 修正 | 失败（退化段 2001） | 需要路径包装器 |
| 3 | 手写坐标 + 通用行 | 失败（rv 反向） | rv 由邻居派生，不能想当然 |
| 4 | 网格算法 | 失败（方向参数传反） | 水平段必须按**流动顺序**传参 |
| 5 | 网格算法 + 修正 | **链条连通，仅拐角 rv 未定** | **精确定位到唯一障碍** |

**每一步失败都让"问题"更窄、更精确** —— 从"布局很难"（模糊）到
"拐角格的 rotationVariant 需要邻居就位后重放或用蓝图显式指定"（**可实现的工程需求**）。

**这就是研究该有的样子**：不是"失败了"，而是"把未知缩小到了一个具体的技术点"。
