## 第二轮挖出的 9 个问题，逐条修法

### 1. 我上一版的修复本身有 bug（最该反省）

第一轮验收说"G3 在 rot=180/270 失明"，我据此给桥加了负方向分支：

```js
const ox = (r === 180 || r === 270) ? -(w - 1) : 0;
for (let cx = 0; cx < w; cx++) for (let cy = 0; cy < h; cy++) {
    if (cx === 0 && cy === 0) continue;        // ← 平移前的 (0,0)
    cells.push([wx + ox + cx, wy + oy + cy]);
}
```

`ox = -1` 时该跳过的是 `(cx=1, cy=0)`，我跳的是 `(cx=0, cy=0)`。
**结果只查了 origin，左半格仍然漏检**——修了个寂寞，而且第一轮验收同样没查出来。

正确写法：先算世界坐标再比。

```js
const px = wx + ox + cx, py = wy + oy + cy;
if (px === wx && py === wy) continue;
```

**教训**：修 bug 时必须验证"修复前的失败用例现在通过了"，
而不是"代码看起来改了"。我改完只跑了 mod 自测（28 条全过），
但那些测试根本不覆盖这个场景。

### 2. step 期间时间片不轮转（致命，放大 2.68×）

`stepTicks` 只调 `root.time.performTicks()`，而
`productionAnalytics.update()` 只在 `core.tick()` 里被调用（core.js:286-296）——
后者是**唯一**让时间片轮转的地方。

所以整个 step 期间 40~60 秒的产量全压进当前最后一片，
而 G6 按 `总量 / (片数 × 10秒)` 折算 → 放大数倍。

实测：真实 0.5/s 的线在 `step 7200 + 4800` 后报 1.34/s。

修：`stepTicks` 每次 `performTicks` 后也调 `productionAnalytics.update()`。

**成本**：`update()` 只是一个时间比较（`if (now - lastSlice > 10)`），
每 10 游戏秒才真正 `startNewSlice()`。实测 50μs/tick 全是 `performTicks` 本身的成本，
我的改动几乎零开销。

### 3. G6 仍是全厂口径

给同一目标加第二条线时，老线自己的产出就超过阈值。
文档写着"本线的贡献"，代码做的是全厂。

修：加贴前基线，判据改成
```
rate_after >= max(target, baseline + target * 0.5)
```
即"贴后必须比贴前明显更高"，否则报"被既有产能掩盖，无法归因"。

宁可判"不能证明"，不判"看起来达标就通过"。

### 4. 刚读档必假红

`startNewSlice()` 在构造时 push 满 100 个空片，
所以"`slices.length < 2`"这个保护永远不触发。
读档后立刻采样得到 `[{},{},{},{},{},{"RuRuRuRu":2}]` → rate=0 → 红。

修：检测"所有片都空" → undecidable（不是"零产出"）。

### 5. gateClock 的 240Hz 假红

下界用 `probeTicks / 120` 硬编码了 tickRate。
游戏的 `refreshRateOptions` 是 `[30,60,120,180,240]`，
240Hz 下"请求 600 tick"只需 2.5 秒，判据却要求 3 秒 → 健康游戏被判死。

修：用 `debug_loop.tick_rate`。

**误差方向分析**：如果 tick_rate 误报成更高值，下界更松（更保守），
不会假红。误报成更低值才会假红，但那意味着游戏自己报错了自己的配置。

### 6. 回滚在 A3 场景必拒绝

`before.byUid` 里含已被 paste 销毁的实体，被当成"外人"→ 拒绝回滚。
而那正是最需要回滚的场景（新实体恰好覆盖旧实体的格）。

修：只在 `after.byUid` 里**还活着**的才算外人。

### 7. debug_items region 写死

`[-80,-80,80,80]`，蓝图在范围外时 G6b 覆盖为空 → 假红。
修：按 intent 的 bbox + pad 算。

### 8. gateG6 的 prod1 从未使用

签名收两个采样但只用第二个。
现在用它作基线（见第 3 条）。

### 9. 测试有字面相同的断言

`gates.test.mjs` 有两行 `mkSlices(10,6)` 对着自己比，注释却说是"回归锁"。
已改成基线 + 采样两参数，并新增三条锁。
